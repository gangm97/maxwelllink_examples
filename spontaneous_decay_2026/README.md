# 2026 Spontaneous Decay

This folder contains the simulation inputs, plotting scripts, and relevant data for the spontaneous decay study using MaxwellLink.

## Contents

- `inputs/`: Input files for the spontaneous decay simulations.
- `plotting/`: Python scripts for plotting and post-processing the results.

**Caution:** [MaxwellLink v0.4.1](https://github.com/TaoELi/MaxwellLink/releases/tag/v0.4.1) was used to perform this research. There is no guarantee that a newer version of MaxwellLink will exactly reproduce the same results, as the input variables and implementation details may change in later updates. Please always use [MaxwellLink v0.4.1](https://github.com/TaoELi/MaxwellLink/releases/tag/v0.4.1) to reproduce this research.
